# Test Writing Skill
1. Read the source file being tested to understand all edge cases
2. Write tests covering happy path, error cases, and boundary conditions
3. Run the test suite and fix any failures
4. Ensure no test relies on default time values (use explicit timestamps)
5. Run coverage report and note uncovered lines
